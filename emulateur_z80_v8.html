BitFlagSignification

                
7SSign — résultat négatif (bit 7 = 1)

                
6ZZero — résultat = 0

                
5—Non utilisé (copie du bit 5 du résultat)

                
4HHalf-carry — retenue du bit 3 au bit 4

                
3—Non utilisé (copie du bit 3 du résultat)

                
2P/VParity/oVerflow — parité ou débordement signé

                
1NAdd/Subtract — 0=addition, 1=soustraction (pour DAA)

                
0CCarry — retenue ou emprunt

Instructions qui affectent les flags

              

                ADD/ADC/SUB/SBC → S Z H P/V N C

                AND/OR/XOR → S Z H=0 P N=0 C=0

                INC/DEC → S Z H P/V N  (C inchangé)

                CP → comme SUB mais résultat non stocké

                RLC/RRC/RL/RR → S Z H=0 P N=0 C

                RLCA/RRCA/RLA/RRA → H=0 N=0 C  (S,Z inchangés)

                LD/PUSH/POP/JP/CALL/RET → aucun flag

⌨️ Clavier — TRS-80
          
            Matrice: PORT A=$40 (lignes OUT) · PORT B=$41 (colonnes IN) — PS/2: CLK→/INT · DATA=PIO3 $61 bit0
          
        

        
        

          Entrée clavier :
          
          
        

        

          

            
⌨️EN ATTENTE — Appuyez sur une touche

            
Shift: OFF

            

          

          
          

            
Clavier PS/2 simulé

            
Bit DATA courant : —

            
Bits en attente : 0

            

              Tapez au clavier physique : chaque touche part comme une

              trame Set 2 complète (start+8bits+parité+stop) sur DATA,

              avec une impulsion /INT par bit (IM1 → $0038).

              Un bit n'avance que lorsque le précédent a été traité —

              aucune perte si le programme Z80 tourne lentement.

              Supporté : a-z, A-Z (Shift auto), 0-9, espace.

Col retournée: —

            

              OUT $40 → sélection ligne (1 bit actif)

              IN $41  → colonnes appuyées (bit=1)

              Scan en cours: E=00000001b, RLC x8
